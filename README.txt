STUDIOM BY MANYA MEHROTRA
Warm Neutral Full Website + Cart + Razorpay-ready Checkout

HOW TO RUN
1. Install Node.js 18+
2. Open this folder in Terminal
3. Run: npm install
4. Copy .env.example to .env
5. Put your Razorpay TEST key and secret in .env
6. Run: npm start
7. Open http://localhost:3000

WHAT IS INCLUDED
- Warm neutral StudioM theme
- Rolling/rotating wall hero
- Artist + wall art section
- Large Available Works section
- Artwork detail popup
- LocalStorage cart
- Popup checkout
- Razorpay-ready Node backend
- Supplied images prepared/cropped for the layout
